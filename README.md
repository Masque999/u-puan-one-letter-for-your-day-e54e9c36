# One Letter for Your Day

Exactly one letter, A to Z, standing for the word that describes the day.

Entry: `Z`

The word behind the letter: zero sleep — a day that started before sunrise on bounty work and never slowed down.

Run: `node main.ts` (writes the letter to `/output/entry.txt`).
